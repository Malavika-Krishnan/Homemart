## 📖 About HomeMart

**HomeMart** is a modern grocery planning application designed to make household shopping simple and organized.

Instead of carrying paper shopping lists, users can digitally manage their grocery needs, organize products into categories, track items to purchase, and enjoy a cleaner shopping experience.

Whether you're shopping weekly or planning a monthly grocery run, HomeMart helps ensure you never forget an essential item.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/HomeMart.git
```

Move into the project

```bash
cd HomeMart
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

# 🎯 Why HomeMart?

Shopping can quickly become chaotic when relying on memory or handwritten lists.

HomeMart provides a simple digital solution by helping users:

- 🥦 Plan groceries in advance
- 🧾 Organize shopping efficiently
- 💰 Avoid unnecessary purchases
- 🏠 Manage household needs
- ⏱ Save shopping time
- 📱 Access lists from anywhere
